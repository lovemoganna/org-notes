# DuckDB × Excel — SQL 图解素材

本目录保存 **82 张可编辑 SVG 原稿**（15 张章节图、67 张小节机制图）。

发布版 PNG 位于 `note-assets/1a5d49f3-4ac5-49cc-a1cd-48c014530351/`，与本目录 SVG 同名但扩展名为 `.png`。文章源文件位于 `notes/programming/duckdb-excel-relation/1a5d49f3-4ac5-49cc-a1cd-48c014530351.org`。

**为什么发布版采用 PNG：** 当前固定版本的 Org Museum 发布器对 Org 正文引用 SVG 会报 `asset: unsupported format or attachment larger than 20 MiB`，因此保留 SVG 作为源稿，Org 引用 PNG 以保证兼容。

图解遵循统一语义：蓝色表示运算或流程；青绿色表示保留或匹配；琥珀色表示未匹配但保留；红色表示删除或失效。仅依据示例解释概念；未提供 fixtures 的 CSV/Parquet 图不代表实测查询输出。
