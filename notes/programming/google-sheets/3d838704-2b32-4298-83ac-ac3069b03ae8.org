同一个起止日期可以得出两个正确答案：自然日间隔和应工作的日期数。先把日期输入成可计算的值，再决定统计口径。这篇同时教你识别导入的金额字符串、零、真空格和看起来空白的公式。

例题使用 Google Sheets 的英文函数名，以逗号分隔参数。若工作簿使用不同的地区设置，请在文件设置中切换到美国地区，或相应调整参数分隔符和小数格式。

* 把值填到指定位置

打开空白 Google Sheets，按下表填写。带等号的内容直接键入格内。D2 和 D3 开头的单引号用于保留文本类型，它不会显示在格内。

| 单元格 | 键入 | 用途 |
|--------+------+------|
| A2 | ~=DATE(2026,11,16)~ | 开始日期 |
| B2 | ~=DATE(2026,11,23)~ | 结束日期 |
| C2 | ~=DATE(2026,11,18)~ | 指定假日 |
| D2 | ~'125.50~ | 导入的金额文本 |
| D3 | ~'00023~ | 保留前导零的编号 |
| E2 | ~0~ | 实际数值零 |
| F2 | 留空 | 真空格 |
| G2 | ~=""~ | 公式输出空字符串 |
| A3 | ~=DATE(2026,11,21)~ | 已知的周六 |

DATE 第三个参数是日号。选中日期格，把显示格式暂时换成数字，看到的是底层日期序列值。换回日期后，值仍然能比较、相减和排序。需要固定结算截止日时，把日期值写在单独一格。TODAY() 会随文件时区和重算更新，适合当天报表，不适合直接充当过去某次结算的证据。

* 取年月日或星期

在右侧空格分别输入：

#+begin_example
=YEAR(A2)
=MONTH(A2)
=DAY(A2)
=WEEKDAY(A3,2)
=TODAY()
#+end_example

前四项依次为 2026、11、16、6。WEEKDAY 的第二个参数 2 表示周一为 1，所以周六是 6。改成 1 后，周日为 1，周六会变成 7。仅用 MONTH 分组会把不同年份的同月合并，跨年报表至少同时保留年份或完整年月。

DATE 会规范化部分越界参数。若业务要求拒绝「11 月 31 日」，在输入处验证日期，别把 DATE 返回的下月日期当成输入合格。

* 两种天数的分母

#+begin_example
=DATEDIF(A2,B2,"D")
=NETWORKDAYS(A2,B2,C2)
#+end_example

第一条返回 7。单位 D 按自然日算从 16 日到 23 日的间隔。第二条返回 5。闭区间中有六个周一至周五的日期，扣掉 18 日这个人为指定的假日后剩五个。NETWORKDAYS 计入符合条件的起止日。国家或团队的休息日须显式提供，可传入一段假日范围。

做一个边界实验：把 C2 改为周六 11 月 21 日。工作日结果变成 6，因为周六本来已排除。自然日间隔保持 7。若工作日多算或少算一天，先核对起止日实际是否含在业务区间，再核对是假日表还是日期列出了问题。

* 输入看起来一样，类型可能不同

#+begin_example
=ISNUMBER(D2)
=ISTEXT(D2)
=VALUE(D2)+1
=TEXT(1234.5,"#,##0.00")
=ISBLANK(E2)
=ISBLANK(F2)
=ISBLANK(G2)
=EXACT("BTC","btc")
#+end_example

结果依次是 FALSE、TRUE、126.5、文本 1,234.50、FALSE、TRUE、FALSE、FALSE。VALUE 解析文本数字后可继续算，TEXT 则生成带显示格式的字符串。保留真实金额列用于汇总，另建文字列用于拼接标签。默认保留带前导零的编号为文本，即使 VALUE 能将 D3 转成 23。

E2 的 0 有内容，G2 有一条公式，只有空的 F2 通过 ISBLANK。EXACT 可用来核查大小写或尾随空格。日期属于数值，所以 ISNUMBER 也会放过普通数字 7。验证业务时间时，还要判断它是否落在合理日期区间。

* 独立练习

假设 23 日是新的指定假日，且 18 日恢复工作。先用手指数 16 至 23 日剩哪些工作日，再改变 C2。工作日应仍为 5，自然日仍为 7。随后在 F2 先填 0、再填 ~=""~，最后清空。逐步预测 ISBLANK 的三个结果，应依次为 FALSE、FALSE、TRUE。
