成交表里可能有重复订单号、文本时间，甚至一个恰好能通过数值检查的普通数字。下面从一张六行成交表出发，先逐行确认数据，再用半开时间窗口汇总。最后把筛选、去重和缺失处理组合起来。

例题使用 Google Sheets 的英文函数名，以逗号分隔参数。若工作簿使用不同的地区设置，请在文件设置中切换到美国地区，或相应调整参数分隔符和小数格式。

* 建一张有反例的练习表

新建 Google Sheets，把下面数据粘贴到 A1:E7。A 列四个有等号的值是日期时间公式。如果粘贴后显示为公式文字，逐格重新键入。把 A2:A7 设成日期时间格式，保留 A5 的底层数字 7。设成日期格式后，它看上去像个旧日期，正好可以用来测试业务校验。

#+begin_example
成交时间	方向	订单号	金额	状态
=DATE(2026,11,18)+TIME(10,1,0)	买入	B101	120	待处理
=DATE(2026,11,18)+TIME(10,3,0)	买入	B101	80	已结案
=DATE(2026,11,18)+TIME(10,5,0)	卖出	S101	150	待处理
7	买入	坏键	999	待处理
=DATE(2026,11,18)+TIME(10,15,0)	买入	B102	200	待处理
坏时间	卖出	S102	50	待处理
#+end_example

把 F1 命名为有效时间。在 F2 写判断式，向下填到 F7。

#+begin_example
=AND(ISNUMBER(A2),A2>=DATE(2026,1,1),A2<DATE(2027,1,1))
#+end_example

预期是 TRUE、TRUE、TRUE、FALSE、TRUE、FALSE。分开看 A5：~=ISNUMBER(A5)~ 是 TRUE，因为 7 确实是数字。加上业务年份区间以后才是 FALSE。对 A7，类型检查本身就不通过。实际项目中把年份换成数据允许的最早与最晚日期。

* 让筛选结果带上表头

先在 J2 输入 ~=FILTER(A2:E7,F2:F7)~。应该得到第 2、3、4、6 行。确认明细正确后，清空 J2，把结果替换为：

#+begin_example
=VSTACK(A1:E1,IFNA(FILTER(A2:E7,F2:F7),{"无匹配","","","",""}))
#+end_example

FILTER 先返回有效行，IFNA 只在没有匹配时返回一行五列的提示，VSTACK 再把表头放在前面。用五列后备值是为了保持没有数据时的列宽。需展示原表的空白字段时，可以把 FILTER 的第一参数换成 ~=IF(A2:E7="","",A2:E7)~ 所代表的表达式，直接放入公式时去掉它开头的等号。先用一个带空字段的样本验证导出结果。

* 让每笔成交只进入一个窗口

分别填 H2 和 H3。H2 是窗口起点，H3 是终点，均为日期时间。

#+begin_example
=DATE(2026,11,18)+TIME(10,0,0)
=DATE(2026,11,18)+TIME(10,15,0)
#+end_example

统计的是 [10:00, 10:15)：起点计入，终点留给下一组。用下面的公式算买入金额：

#+begin_example
=SUMIFS(D2:D7,B2:B7,"买入",F2:F7,TRUE,A2:A7,">="&H2,A2:A7,"<"&H3)
#+end_example

结果为 200，来自第 2、3 行的 120＋80。第 6 行恰好是 10:15，不能算在这个窗口。复制报表时，如果共享同一对时间条件，可将 H2、H3 写成 $H$2、$H$3 固定引用。要按行滚动时间窗口则保留对应的相对行。

如果手里只有成交时间，想先求所在的 15 分钟桶起点，可用 ~=FLOOR(A2,15/1440)~。日期时间以天计，15 分钟是一日的 15/1440。把结果设成日期时间显示，就能看到 10:00。

* 区分成交笔数和订单数

把以下内层公式单独放到空白区。当前会得到两行 B101。

#+begin_example
=FILTER(C2:C7,B2:B7="买入",F2:F7=TRUE,A2:A7>=H2,A2:A7<H3,C2:C7<>"")
#+end_example

每行是一笔成交，两笔来自同一张订单。核对内层输出后，再加 COUNTUNIQUE 和 IFNA：

#+begin_example
=IFNA(COUNTUNIQUE(FILTER(C2:C7,B2:B7="买入",F2:F7=TRUE,A2:A7>=H2,A2:A7<H3,C2:C7<>"")),0)
#+end_example

结果是 1。如果统计窗口移到没有匹配的时段，结果为 0。若还要对账，用 COUNTIFS 按相同时间和方向计行数。这里会得 2。金额、笔数和去重订单数是三个不同口径，分别保留。

* 独立练习

把 H2 改为 ~=DATE(2026,11,18)+TIME(10,15,0)~，把 H3 改为同一天的 10:30。这里直接用 DATE 与 TIME 构造两个边界，使 10:15 的输入与窗口条件按同样方式生成。再次核对：应只有 B102，买入金额 200，买入成交 1 笔，买入订单 1 个。再把窗口设为当天 10:30 至 10:45，确认买入金额与去重订单数都为 0。若窗口之间重复计数，先检查上一窗的上界是否写成 <=。若订单数跳高，检查内层是否排除了空 ID，以及是否误把一笔成交当成一个订单。

#+end_src

- ~">="&G2 / "<"&G3~  对 A 列分别检查含起点和不含结束时间。

#+end_src

- ~B2:B7 / "买入"~  检查成交方向。
- ~A2:A7 / ">="&G2~  检查开始时刻及之后。
- ~A2:A7 / "<"&G3~  截止时刻本身留给下一窗。

*** H4 数窗口内有几张不同的买入订单

#+begin_src excel :eval never
=LET(keys,FILTER(C2:C7,
  (B2:B7="买入")*(A2:A7>=G2)*(A2:A7<G3)*
  (C2:C7<>""),
  ""),IF(INDEX(keys,1)="",0,
  ROWS(UNIQUE(keys))))
#+end_src

- ~FILTER(...) / * / ""~  从 C 列筛买入且在时间窗内的非空订单号，星号要求各条件同时成立，没有匹配就返回空文本。
- ~LET(keys,...)~  给筛出的名单起名 keys，后面重复使用。
- ~IF / INDEX / ROWS / UNIQUE~  INDEX 读首项，IF 遇空返回 0，UNIQUE 去重，ROWS 数行。

同一订单可以分成多笔成交。计算订单数时要先按订单号去重。Excel 回读为 1。
[[https://lovemoganna.github.io/org-notes/assets/excel-formula-video-course/index.html?formula=H4#23][查看彩色公式及参数讲解]]（1:39）。

** 24 SUMIFS / COUNTIFS / LET / FILTER / IF / INDEX / ROWS / UNIQUE · 独立做报表：一套条件驱动金额、笔数和订单数

在跟练工作簿打开工作表 =24=。[[https://lovemoganna.github.io/org-notes/assets/excel-formula-video-course/index.html#24][观看这节课]]（3:02）。[[https://lovemoganna.github.io/org-notes/assets/excel-formula-video-course/lessons/24/lesson.mp4][MP4]]。

本例起始输入为 G2 为 ~=DATE(2026,11,18)+TIME(10,0,0)~，G3 为 ~=DATE(2026,11,18)+TIME(10,15,0)~，G4 为 ~买入~。

*** H2 汇总指定时间和方向下的成交金额

#+begin_src excel :eval never
=SUMIFS(D2:D7,B2:B7,G4,A2:A7,">="&G2,A2:A7,"<"&G3)
#+end_src

- ~D2:D7~  成交金额列。
- ~B2:B7 / G4~  按 G4 的方向匹配成交。
- ~">="&G2 / "<"&G3~  在 A 列检查含起点、不含结束时刻的时间窗。

做可切换买入、卖出等方向的报表时，改输入即可刷新金额。Excel 回读为 200。
[[https://lovemoganna.github.io/org-notes/assets/excel-formula-video-course/index.html?formula=H2#24][查看彩色公式及参数讲解]]（1:07）。

*** H3 数指定条件下的成交笔数

#+begin_src excel :eval never
=COUNTIFS(B2:B7,G4,A2:A7,">="&G2,A2:A7,"<"&G3)
#+end_src

- ~B2:B7 / G4~  匹配方向。
- ~A2:A7 / ">="&G2~  确认在开始时刻或之后。
- ~A2:A7 / "<"&G3~  使用不含终点的边界，COUNTIFS 数命中行。

报表要同时展示金额和笔数时，这条公式提供相同筛选口径的笔数。Excel 回读为 2。
[[https://lovemoganna.github.io/org-notes/assets/excel-formula-video-course/index.html?formula=H3#24][查看彩色公式及参数讲解]]（1:27）。

*** H4 数指定条件下的独立订单

#+begin_src excel :eval never
=LET(keys,FILTER(C2:C7,
  (B2:B7=G4)*(A2:A7>=G2)*(A2:A7<G3)*
  (C2:C7<>""),
  ""),IF(INDEX(keys,1)="",0,
  ROWS(UNIQUE(keys))))
#+end_src

- ~FILTER(...) / * / ""~  按 G4 方向、G2 到 G3 时间窗筛 C 列的非空订单号，星号要求条件同真，无匹配返回空文本。
- ~LET(keys,...)~  把筛出的订单号列表命名为 keys。
- ~IF / INDEX / ROWS / UNIQUE~  INDEX 读首项，IF 遇空返回 0，UNIQUE 去重，ROWS 数行。

一个订单可能分成多笔成交。用它核对笔数和订单数是否相同。Excel 回读为 1。
[[https://lovemoganna.github.io/org-notes/assets/excel-formula-video-course/index.html?formula=H4#24][查看彩色公式及参数讲解]]（1:47）。

*** H5 根据成交笔数和订单数生成对账标签

#+begin_src excel :eval never
=IF(H3=0,"无成交",IF(H3=H4,"逐笔对应","有拆单"))
#+end_src

- ~H3=0 / "无成交"~  先处理零笔成交。
- ~H3=H4 / "逐笔对应"~  有成交时比较笔数与独立订单数。
- ~"有拆单"~  两者不相等时用这个标签。

需要让读报表的人知道窗口内是否有拆单时，用这条规则输出可读标签。Excel 回读为 有拆单。
[[https://lovemoganna.github.io/org-notes/assets/excel-formula-video-course/index.html?formula=H5#24][查看彩色公式及参数讲解]]（2:18）。
