* 做什么
用 Org-Babel 的一段 Python 执行块连续调用两次 Gemini API：Prompt A 提取问题，Prompt B 消费 A 的原始输出并生成开发任务单。执行后的结果由 Org-Babel 写入当前 Org 文件，保存并提交 Git 后由原笔记网站发布。

* 执行方法
1. 在本地 Emacs 打开本 Org 文件，确保 Python 3 可用，并按常规方式启用 =ob-python=；保持 Org 源文件已保存。
2. 在本机凭据管理方式中提供环境变量 =GEMINI_API_KEY=；可选 =GEMINI_MODEL=（默认 =gemini-2.5-flash=）。不要把密钥写入本文件、终端历史或 Git。只公开不敏感的任务材料及输出。
3. 在下方 =run-prompt-chain= 代码块按 =C-c C-c=，检查授权确认。Org-Babel 将原文件绝对路径传入 Python，执行两次真实模型调用，且 B 完整接收 A 的原始文本。
4. Babel 自动把输出写入代码块下方的 =#+RESULTS=。检查内容后保存 Org，提交同一篇新笔记的 Git 路径；站点现有 CI 只导出，不执行 API 代码。
5. 没有凭据、网络或模型返回文本时，保留 =BLOCKED= 或失败记录，不把模拟数据当真实结果。不重复发布新文章。

from datetime import datetime, timezone
from pathlib import Path
import hashlib
import json
import os
import re
import subprocess
import sys
import urllib.error
import urllib.request


def example_in_section(lines, title):
    """Read the literal prompt body directly from its Org section."""
    start = lines.index(title)
    begin = next((i for i in range(start + 1, len(lines)) if lines[i] == "#+begin_example"), -1)
    if begin < 0 or any(lines[i].startswith("** ") for i in range(start + 1, begin)):
        raise ValueError("Missing example in " + title)
    end = next((i for i in range(begin + 1, len(lines)) if lines[i] == "#+end_example"), -1)
    if end < 0:
        raise ValueError("Unclosed example in " + title)
    return "\n".join(lines[begin + 1:end]).strip()


def gemini(prompt, key, model):
    # No key ever appears in the URL, payload, output or versioned Org file.
    if not re.fullmatch(r"[A-Za-z0-9._-]{1,100}", model):
        raise ValueError("Invalid GEMINI_MODEL")
    url = "https://generativelanguage.googleapis.com/v1beta/models/" + model + ":generateContent"
    request_body = {
        "contents": [{"role": "user", "parts": [{"text": prompt}]}],
        "generationConfig": {"temperature": 0.2, "maxOutputTokens": 2048},
    }
    req = urllib.request.Request(
        url,
        data=json.dumps(request_body, ensure_ascii=False).encode("utf-8"),
        headers={"Content-Type": "application/json", "x-goog-api-key": key},
        method="POST",
    )
    try:
        with urllib.request.urlopen(req, timeout=90) as response:
            payload = json.load(response)
    except urllib.error.HTTPError as exc:
        raise RuntimeError("HTTP " + str(exc.code) + " from Gemini API") from None
    except (urllib.error.URLError, TimeoutError) as exc:
        raise RuntimeError("Gemini API network or timeout failure") from None
    choices = payload.get("candidates") or []
    parts = choices[0].get("content", {}).get("parts", []) if choices else []
    output = "".join(item.get("text", "") for item in parts)
    if not output.strip():
        raise RuntimeError("Gemini returned no text; check safety/finish reason separately")
    return output, payload.get("modelVersion", model)

* 复现边界
- 该实验验证调用与记录链路，不替代 PivotStudio 实际代码修改。
- =:eval never-export= 阻止网站构建执行这段代码；执行应在授权的本地 Emacs 内进行。
- 每次调用都可能产生模型 API 使用费用；当前不自动重试。
- Babel 原生结果写入同一份新 Org 文件。变更应在 Git 提交后才会出现在网站上。
