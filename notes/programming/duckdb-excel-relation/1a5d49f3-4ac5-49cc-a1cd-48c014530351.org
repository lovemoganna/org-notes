为表列或表达式建立持久化 ART 二级索引；可加速高选择性点查，UNIQUE INDEX 同时约束重复值。它改变访问路径，不改变表的逻辑 Relation。

Relation：Table 数据 → 建立持久索引访问路径；输出 Relation 结构不变，优化器可改变扫描方式

** 统一业务字段类型 · 枚举 / STRUCT / UNION 复用
DuckDB 概念：User-Defined Type (持久化自定义类型)。SQL 入口：CREATE TYPE。

在 Catalog 中定义可复用数据类型，如 ENUM、STRUCT、UNION 或类型别名；让多个表共享一致的字段语义与结构定义。

Relation：类型定义 → 注册为 Catalog 数据类型；不产生 Relation，后续表列可直接引用

CREATE TABLE people(id INTEGER, state mood);
