* 怎么跟练

先选一章，在播放器里看原例输入、关键 SQL 和实际输出。暂停后打开跟练包中对应的小节，运行 =run.sql=，再和 =result.json= 对照。=original.sql= 保留原文代码。

- 普通查询的样本大多写在 =VALUES= 里，可直接复制到 DuckDB 运行。
- CSV 和 Parquet 两节从跟练包根目录运行。脚本会先把内嵌样本写入 =fixtures/=，再用原文查询读取。
- 创建或挂载对象时用独立练习连接。验证持久化时，关闭并重开同一个练习数据库文件，再运行 =verify-reopen.sql=。
- 配套原例使用 DuckDB 1.4.0 验证。随机抽样小节核对样本量和取值范围，未指定排序的查询按行集合核对。
