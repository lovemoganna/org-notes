* 如何使用
本页扫描对象为 GitHub 账户 lovemoganna 当时可见的 63 个自有仓库的默认分支。基线共发现 89 个名为 SKILL.md 的文件，分布于 4 个仓库；其中 2 个是同名入口副本，1 个是规范模板，故实际可按名称区分的 Skill 为 86 个。其余仓库未发现 SKILL.md；AutoPlantuml 和 cryptocurrency_monitor 为空仓库，无法检查源码。
注意：GitHub 上存在 Skill 文件，不等于当前 ChatGPT、Claude Code 或其它运行环境已经安装它。实际调用取决于平台是否识别该路径、是否加载对应工具与依赖。
推荐直接在当前对话中指定 Skill 的确切名称、GitHub 源码路径、任务输入和交付要求；使用本页的调用示例即可。
#+begin_example
读取以下仓库 Skill 的当前 SKILL.md 和实际依赖，并按规则执行：
https://github.com/lovemoganna/Org-Skills/blob/main/skills/ontology-constrained-analysis/SKILL.md

禁止用仓库旧测试结果冒充本次运行。
#+end_example
