* 使用边界
1. =自动选择最佳输出形式= 用于尚未决定呈现形式的任务；选定图或 HTML 后，再调用对应的专业 Prompt，不需要每次套上全部提示。
2. =图解优先= 可以选择普通关系图；明确要求可渲染 PlantUML 时使用 =PlantUML 自主选图=，如要求 SQL 的真实执行计划须提供 EXPLAIN 等证据。
3. =讲解视频生成= 默认产出分镜和制作方案，不代表运行环境一定能渲染出视频。=HTML 交互解释器= 要求单文件、无需后端，但仍需要实际打开验证。
4. =概念核验与深度学习资料检索=、=LinkedIn 加密风险情报博文生成= 都要求真实外部来源；无法联网时不能假装完成核验。
5. =Twitter / X 技术 Thread 生成= 依赖已有事实材料，不能让模型补造经历；=LinkedIn 加密风险情报博文生成= 还需要判断是否有公开发布价值，不足时可拒绝成稿。
6. =Prompt 仓库分类与归档= 负责新增或维护 Prompt，必须同步 README；不能把它替代为 Skill 的测试或发布流程。
