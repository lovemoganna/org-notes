提示词的质量，最终要看同一任务下的实际输出是否满足要求。清晰表达、必要上下文、自然语言和迭代优化是四个设计方向；它们是*检查输入*的方法，而不是未经测量就能证明有效的分数。

* 四项原则

| 原则 | 要检查什么 | 具体动作 |
|------+----------------------+------------------------------|
| 清晰具体 | 动作、对象、交付物是否可辨认 | 改掉“写点好的”一类无法验收的表述 |
| 必要上下文 | 目标读者与使用场景是否明确 | 补可用材料、边界、约束和术语 |
| 自然简洁 | 是否有重复、歧义或相互冲突的指令 | 删除不改变任务的空话，保留必要条件 |
| 实验迭代 | 是否保存了真实输入与输出 | 固定基线，一次修改一个主要因素 |

* 选哪一项先修〔补〕

1. *没有回答核心任务*：先改指令，说明动作、对象和成功条件。
2. *方向对但不能落地*：核查输入来源、受众、具体字段与业务限制，再补背景。
3. *输出过于宽泛*：给一两个可核验的例子或明确输出约束；不要直接堆更多角色描述。
4. *改了提示却不知道是否更好*：使用相同任务样本，记录模型版本、提示版本、输出和失败原因，再决定是否保留新版本。

四项原则没有统一的先后等级。先定位本次最影响任务结果的缺口，再做最小修改。

* 怎样测量

将*输入规则是否清楚*与*输出结果是否达标*分开。源材料列出了多种用于内部分析的指标，其中部分有可直接计算的形式，但是否有价值取决于对照样本与评分口径。

| 指标 | 可保留的计算方式 | 必须先满足的条件 |
|------+------------------+------------------|
| 需求覆盖率 | 正确满足的需求点数 ÷ 已定义需求点总数 | 先固定需求清单，定义“正确满足” |
| 约束满足率 | 输出满足的明确约束数 ÷ 约束总数 | 检查每条约束，不能只数条目 |
| 上下文完备度 | 已提供的必要背景项 ÷ 经确认的必要背景项 | 必须先确认什么叫“必要” |
| 修改收益 | 同口径质量分数之差与回归失败数 | 同一组输入与评分标准，保留实际响应 |

*不能直接当标准的数字*：原稿提出需求覆盖率 ≥90%、平均句长 15–20 字、冗余度低于 20%、困惑度低于 100、通常 3–5 轮迭代，以及自定义 PQS 加权公式。**这些阈值没有附上可验证的模型、任务、数据集和实验方法**，应视为历史示例值，不是行业统一门槛；尤其不能用低困惑度证明提示更正确。完整表述与公式见来源附件。〔补〕

* 一次可复验的改进

1. *明确任务*：固定目标、输入、失败案例及不可更改条件。
2. *保存基线*：记录当前提示、模型及其真实输出。没有真实输出时记为“未执行”。
3. *修改一处*：只修已找到的最高优先级缺陷。
4. *同样验证*：用相同样本与评分口径比较内容正确性、漏项、可用性及副作用。
5. *决定去留*：只有实际提升且旧案例不退化才保留；否则回退。〔补〕

可复用的思路是：*先发现具体失误，再设计针对该失误的检查。* 测试数量、句子长度及公式本身不代表提升。 

* 示例提示与示例结果

这是一份用于编写产品问题陈述的*教学样例*，不是已经验证支付接口存在故障或优化到了 2 秒的现场记录。

** 原始提示

#+begin_src text
"作为一名产品经理，请帮助我撰写一份问题陈述，格式如下：
问题：描述需要解决的具体问题
原因：解释问题的成因
影响：说明问题对用户或业务的影响
目标：阐明希望达成的目标"
#+end_src

** 来源示例输出

#+begin_src text
问题：用户在移动端支付时经常遇到卡顿现象。
原因：支付接口的响应时间过长，且缺乏优化。
影响：降低了用户体验，导致支付成功率下降。
目标：优化支付接口性能，将响应时间缩短至2秒以内。
#+end_src

“支付成功率下降”和“响应时间缩短至 2 秒以内”仅属于案例设定或目标，不是本项目的实测结论。

* 校验边界

- *指标要有分母*：模糊词计数、上下文覆盖比例等如果没有明确定义“什么算必要 / 模糊 / 合格”，就不能跨任务比较。
- *权重未校准*：原稿 PQS = 0.3×覆盖率 + 0.25×上下文完备度 + 0.2×(1－冗余度) + 0.15×收敛轮次倒数 + 0.1×(1－歧义率)；分母、权重和量纲并未验证，不建议直接当成标准评分器。〔补〕
- *模型差异*：不同模型或版本可能采用不同提示习惯，必须按当前任务与模型校验。
- *伦理与限制*：避免把例子推断成真实系统状态，不提供不必要的隐私材料。
- *术语与引用*：材料提到“公司 AI 术语表（链接xxx）”，但没有实际链接；不能据此宣称术语已按某公司规范核对。
