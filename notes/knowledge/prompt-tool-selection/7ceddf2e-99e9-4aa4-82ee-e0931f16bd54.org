* 先问用途，再选工具
| 当前任务 | 优先核查的能力 | 验收方式 |
|----------+----------------|----------|
| 快速起草与维护 | 编辑器、模板库、版本历史 | 能否保存并找回指定版本 |
| 改进模型输出 | 提示对照、迭代、评价器 | 同一任务前后结果是否改善 |
| 连接现有系统 | API、权限、日志、成本 | 能否在自己的运行环境执行 |
| 安全或偏差检查 | 测试样本、失败记录与审查 | 是否留下可复核错误证据 |

* 原文列举的工具
原始材料列出了 IBM watsonx.ai、Spellbook、Dust、PromptPerfect、GitHub、OpenAI Playground、LangChain 与 PromptBase，还提到 promp(l)ify 管理器。这里仅保留为*当时列举的候选名称*，不将其产品归属、版本、定价和可用性当作现时已核验事实。

1. 先打开官方文档核对产品是否仍可用。
2. 查清支持的模型、数据权限和是否可以导出结果。
3. 用同一组任务比较正确率、成本、响应时间和错误恢复；不以宣传文案选型。
4. 对不提供必要证据或无法接入的工具标记为“未验证”。

# 定义原始提示

# 优化提示
optimized_prompt = optimize_prompt(prompt=original_prompt, model="GPT", quality="high")

# 输出优化结果
