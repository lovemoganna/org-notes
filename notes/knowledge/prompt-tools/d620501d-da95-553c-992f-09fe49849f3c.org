* 先选任务，不先选品牌
问清楚需求属于哪种：编辑单条提示词、管理模板与版本、做模型对照，还是通过 API 集成到生产流程。先列可检验的能力，再考察工具，不要因为旧笔记里列过产品就认定其功能今天仍可用。

| 需要什么 | 验证动作 | 错误做法 |
|----------+----------+----------|
| 试写与调参 | 检查编辑器是否可输入变量、保存、重放 | 把宣传页当实测 |
| 团队复用 | 检查版本、权限、追踪与导出功能 | 只看生成体验 |
| 效果对照 | 固定输入与模型，比对真实输出 | 只比回答流畅度 |
| 程序接入 | 查当前官方 SDK/API 文档并实跑 | 复制未经验证的旧代码 |
