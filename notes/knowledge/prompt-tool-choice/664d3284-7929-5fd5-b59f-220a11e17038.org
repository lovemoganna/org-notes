* 按实际任务选工具
来源整理了六类常见功能：提示建议、结构优化、迭代优化、偏差缓解、领域特定支持、模板库。它们用于筛选需求，不证明每款产品现时都提供完整功能。

| 任务 | 核查项 | 实际证据 |
|------+--------+----------|
| 重写同一提示 | 版本比较 | 输入一致的 A/B 结果 |
| 固定输出格式 | 模板与校验 | 格式错误样本 |
| 多模型测试 | 模型与参数控制 | 模型版本、日志 |
| 多步骤处理 | API、权限与异常处理 | 分步执行结果 |
| 专业领域 | 人工审核与数据授权 | 权限及事实来源 |

* 原始候选清单
- =IBM watsonx.ai / Prompt Lab=：来源描述为提示及模型试验平台。
- =Spellbook=：来源归类为编辑与测试工具；其现行品牌归属和功能未经本轮核实。
- =Dust=：来源描述提示链、版本管理和 API 功能。
- =PromptPerfect=：来源描述自动建议及分步优化。
- =GitHub=、=OpenAI Playground=、=LangChain=、=PromptBase=、=promplify=：分别涉及知识资源、模型试验、框架、市场与提示管理，不可混为同一类型。

* 真实选型实验
1. 固定同一个业务输入和验收标准。
2. 核对官方当前版本、计费、模型、数据权限及接入条件。
3. 对所有候选运行同一任务，保存完整输出和异常。
4. 比较实际质量、维护成本与可追溯性，而非宣传页面。
5. 涉及内部数据时，先确定授权边界。
