* 这份模板是审稿器，不是有效性证明
原文是一套“提示词解构与效能评估”的提示模板，包含分析流程、评分维度、使用示例和作者提供的历史判断。未经同任务真实对照，模型生成的 0—10 分不能当成客观性能。

* 推荐的使用顺序
1. 保留待评估提示的原文、目标任务、输入和预期输出。
2. 用原版模板检查任务、上下文、结构、约束与输出格式。
3. 将相关性、深度、创新性、实用性、完整性作为问题发现入口。
4. 对每项建议定位原始失败证据，只做最小修改。
5. 在相同输入和条件下重跑，记录事实错误、遗漏、时间和人工成本。
6. 没有结果证据时将评分标为“模型判断，尚未验证”。

| 维度 | 可以复核的证据 |
|------+--------------|
| 相关性 | 是否解决给定任务 |
| 深度 | 核心机制、条件与例外是否充分 |
| 创新性 | 是否新增有用的判断，而非同义改写 |
| 实用性 | 是否在目标环境真实运行 |
| 完整性 | 是否保留关键素材、操作与失败路径 |

* 来源规则
原始提示、外部参考链接、使用约束与历史评分完整保存在来源附件。下节嵌入原文第一个 Markdown 提示的逐字版本，方便直接复用；它不是这轮新造或已验证的模板。
