* 先弄清楚什么
原稿是一份*用于分析其他提示词的元提示*，附带模型对其自身的评价。两者证据等级不同：模板是真实可复制的来源资产；模型对模板的高分是一次主观输出，不能证明实际效果。

* 五步分析的执行顺序
1. *全面解读*：读完整原始提示，保留目标、关键限制和输入格式，不先润色。
2. *目标定位*：明确要解决的问题、主要使用者与预期产物。
3. *结构剖析*：分出角色、指令、约束、输出模板以及相互冲突项。
4. *效果预测*：列出预期结果及可能失败方式，但标记为预测，不当作已观察事实。
5. *质量评估*：分别评价相关性、深度、创新性、实用性和完整性，并指出依据。

* 模板的不可替代部分
原始提示明确规定分析报告包含“Prompt 名称、援引链接、主要作用、适用场景、结构化分析、质量评估、潜在风险与改进建议”等章节；它还要求输入用“待检测分析的提示词开头/结尾”两条边界包围。*原始提示以及嵌套 Markdown 模板全文*收录在同页的“冻结原文”附件中，避免复制时误删或破坏嵌套代码围栏。

* 把自评和真实效果分开
原稿自评给出相关性 *9/10*、深度 *9/10*、创新性 *8/10*、实用性 *10/10*、完整性 *9/10*。这是材料中模型对元提示自身的评分，并没有测试数据、评分者一致性或跨模型统计支持；*不能将这些数字写成我们的压测成绩*。

* 真实验收怎样做〔补〕
1. 选择至少两段实际业务提示，冻结原文、任务和评估标准。
2. 在同一模型和等价条件下，分别测试原始提示、改写后提示。
3. 记录格式合规、事实错误、遗漏核心限制和人工改动量。
4. 出现异常时追溯目标定位、结构剖析还是评分依据，并保留反例。

* 边界
此模板适合结构分析，但不自动证明提示性能、伦理风险或使用成本；来源中曾出现模型的 *Thinking...* 自述，不应把它提升为独立审稿意见。
