* 这两个图库解决什么问题

[[https://ai-pose-gallery.pages.dev/][POSE-DB-01]] 用无脸灰色人偶展示动作和拍摄角度；[[https://ai-costume-gallery.pages.dev/][COSTUME-DB-01]] 提供服装款式、颜色和材质参考。二者都是素材库，不是生图或换装模型。

使用时将姿势图作为动作参考、服装图作为穿搭参考，面部、背景和光线另外指定。直接组合需要支持多图参考输入的生图工具。

* 第一步：从姿势库选动作

打开 [[https://ai-pose-gallery.pages.dev/][姿势库]]，在「ポーズ名・ID・分類で検索」按名称、编号或分类查找；「ポーズごと」按姿势分组，「1枚ずつ」逐张浏览。

打开大图，比较现有的正面、侧面、斜侧、俯视和仰视视角。优先看重心、手脚位置与相机角度，再点「元サイズをダウンロード（PNG）」保存原图。

桌面端左右方向键切角度、上下切姿势、Esc 关闭。灰色人偶只表示动作，不提供最终人物样貌。

* 第二步：从服装库选穿搭

打开 [[https://ai-costume-gallery.pages.dev/][服装库]]，按类型、季节或风格筛选。先看上衣、下装的轮廓和层次，再确认颜色、布料、图案与配饰；打开大图下载原图。

服装要与姿势兼容。长裙可能遮住腿，宽松外套可能挡住手臂；遇到冲突先换参考图，不要靠增加提示词强行拼接。

* 第三步：给两张参考图分工

在支持多图参考的生图工具中上传姿势 PNG（图 A）和服装 PNG（图 B）。如需固定人物，可再提供已获授权的人物图（图 C）。

#+begin_example
请生成一张成年人写实摄影照片。
图片 A 只用于参考人物动作、身体朝向、重心和拍摄角度；不要复制灰色人偶的外观。
图片 B 只用于参考服装的款式、颜色、材质、层次和配饰；不要复制服装展示图的背景或人偶。
人物为虚构成年模特，面部自然，不套用 A 或 B 的脸。
场景：[地点与时间]。构图：[全身／半身、机位]。
自然光线，合理人体比例，真实皮肤纹理，衣物随动作形成的褶皱与阴影，真实镜头景深。
保留参考图之间不冲突的细节；发生冲突时优先保持人体结构合理，不要强行拼接。
#+end_example

不支持多图参考时，先按姿势图生成基础人物，再通过局部编辑或换装工具参考服装图修改；编辑后复查脸、手和背景。

* 可复制的元提示

以下模板各解决一个任务。图片编号须与实际上传顺序一致；模型不支持对应参考或编辑能力时，不能靠文字保证姿势、服装或身份完全不变。

** 固定人物，只换服装

适合已有成片、只想试穿服装库款式。上传原人物照片 C 与服装参考 B；必须有使用人物照片的权限。

#+begin_example
任务：只换衣服，不重新设计人物。
图片 C 是待编辑的成年人物照片；图片 B 是目标服装。
将 C 的服装替换为 B 的款式、配色、材质与层次。
保持 C 的脸、发型、体型、姿势、取景、背景和光线不变。
按原姿势调整衣服的遮挡、褶皱、松紧和阴影，不要把服装生硬贴在身体上。
输出一张自然摄影效果的图片。除换装必需的局部区域外，不改动其他内容。
#+end_example

** 固定穿搭，只换姿势

适合同一人物、同一套衣服拍多种动作。上传姿势参考 A 与已穿好目标服装的人物照片 C。

#+begin_example
任务：沿用人物与服装，改变动作。
图片 A 只规定新姿势、身体朝向与重心，不提供人物外观。
图片 C 规定成年人脸部特征、发型、身形和现有服装。
把 C 中人物调整为 A 的姿势；保留 C 的人物特征、服装设计、颜色和配饰。
背景：[场景]；机位：[全身或半身、拍摄角度]。
手脚和关节位置必须符合人体结构；衣服随新动作自然产生褶皱与遮挡。
输出一张写实照片。若原服装与动作明显冲突，优先保证人体结构，不要伪造不可能的穿着方式。
#+end_example

** 批量测试：三种姿势 × 三套服装

适合挑选组合，而非直接证明图库控制精度。准备姿势 A1、A2、A3 与服装 B1、B2、B3；尽量固定人物、场景和构图。

#+begin_example
请把上传的姿势 A1、A2、A3 与服装 B1、B2、B3 两两组合，共九组。
每组只改变姿势和服装；固定以下条件：
人物：[同一虚构成年人的面部与身形设定，或已获授权的人物参考]。
场景：[地点、时间和光线]。构图：[画幅、镜头距离和机位]。
输出九张独立图像，按 A1-B1、A1-B2、A1-B3、A2-B1、A2-B2、A2-B3、A3-B1、A3-B2、A3-B3 命名。
每张检查三件事：动作是否吻合 A、衣服是否保留 B 的关键细节、人物是否保持一致。
同时记录可见问题，不把主观印象写成已验证的准确率。
若当前工具无法一次生成九张，按上述顺序分次生成；不要把一张拼图冒充九张独立结果。
#+end_example

** 只修复一处明显错误

适合已有结果整体可用、但手部、衣物或面部存在局部异常。上传待修复图片 D；若要求服装细节更准确，可同时附上 B。

#+begin_example
请局部编辑图片 D，只修复：[具体位置与缺陷，例如右手多出一根手指]。
修复目标：[可观察的正确状态，例如手指数量和握持关系合理]。
保持人物身份、表情、姿势、服装款式、背景、构图及原光线不变。
修复区域的材质、阴影、透视和相邻像素自然衔接，不做整体磨皮、换脸或风格重绘。
输出修复后的图片；如工具不支持局部编辑，应明确说明，不要声称已经保留全部未修改区域。
#+end_example

* 想要更像真实照片，优先改什么

写实感主要取决于人体受力、衣物与身体的接触、光源方向和摄影机位。只加“8K”“杰作”等词无法修复结构问题。

| 现象 | 先检查什么 | 怎么修改 |
|-
| 动作走样 | 选的姿势视角是否和构图冲突 | 固定全身或半身、相机高度和身体朝向；减少互相矛盾的动作描述 |
| 服装像贴图 | 衣服与手臂、肩膀和腰部是否接触合理 | 只要求衣服结构与材质，强调随动作自然产生的褶皱；必要时分阶段换装 |
| 面部像塑料 | 皮肤过度磨皮、双眼过分对称 | 加入自然皮肤纹理和不完全对称的表情；降低浓重美颜及不必要的锐化 |
| 手指、饰品错乱 | 手遮挡衣服、多个配件重叠 | 简化手部姿势或饰品，局部修复并放大检查 |
| 十张都长得相似 | 只改变衣服和背景，没有改变人物设定 | 改变年龄段（均为成年人）、五官、身形、表情、机位与光线 |

* ComfyUI 用户可以怎样接入

偶尔使用可从网页下载 PNG；批量切换组合可用两款第三方中文插件：

- [[https://github.com/Stone-dielianhua/ComfyUI_Pose-Gallery_ZH][ComfyUI_Pose-Gallery_ZH]]：README 记录 288 组姿势、1,439 张参考图；支持侧栏检索、切换视角、单图或批量输出。
- [[https://github.com/Stone-dielianhua/ComfyUI_Costume-Gallery_ZH][ComfyUI_Costume-Gallery_ZH]]：README 记录 1,407 套穿搭；支持季节、类型、颜色筛选，输出服装图及关键词。

插件只负责选图与输出；真正的姿势控制或换装，还需接入兼容的图像参考、控制或编辑节点。代码许可证不代表图片素材也可自由分发。

* 参考图的使用边界

姿势库原站允许免费参考、编辑及作品创作中的商业使用，但禁止转载、再分发、转售原图或加工图，也禁止自动批量下载及将人偶示意用于表现真实人物或未成年人。服装素材的具体许可以原站说明为准；未经核对不得批量抓取或再发布。本篇只展示自行生成的示例，不转载图库原图。
