* 这两个图库解决什么问题

生成一张人物图时，姿势、衣服、脸、背景和摄影风格经常混在同一段提示词里。改衣服可能连姿势一起变；改姿势又可能丢失服装细节。

[[https://ai-pose-gallery.pages.dev/][POSE-DB-01（姿势库）]]提供无脸灰色人体姿态参考，重点是身体动作和镜头角度；[[https://ai-costume-gallery.pages.dev/][COSTUME-DB-01（服装库）]]提供穿搭参考，重点是服装款式、配色和材质。它们是参考素材库，不是人物生成模型，也不负责自动把衣服穿到人身上。

最直接的用法：分别选一张姿势图和服装图，上传到支持多图参考的生图工具，并明确告知模型哪张图只负责什么。

* 第一步：从姿势库选动作

打开 [[https://ai-pose-gallery.pages.dev/][姿势库]]。

1. 在「ポーズ名・ID・分類で検索」（姿势名／编号／分类搜索）输入关键词或编号，也可以按页面筛选项浏览。
2. 通过「ポーズごと」（按姿势分组）与「1枚ずつ」（逐张查看）切换浏览方式。
3. 打开大图，比较正面、侧面、斜侧、俯视与仰视等现有视角。同一动作换角度，人物的可见肢体关系会明显变化。
4. 点击「元サイズをダウンロード（PNG）」下载当前选中的原尺寸 PNG。图像是没有脸的灰色人体示意；不要把示意人的外观误当作最终人物样貌。

桌面端大图界面支持左右方向键切换角度、上下方向键切换姿势、Esc 关闭。选图时优先看身体重心、手的位置、腿的方向和相机机位，而不是只看“站着”或“坐着”的名称。

* 第二步：从服装库选穿搭

打开 [[https://ai-costume-gallery.pages.dev/][服装库]]。

1. 按服装类型、季节或风格浏览，先选整体轮廓，再比较颜色、布料和配饰。
2. 打开服装大图，确认上衣、下装、鞋帽以及容易混淆的层次关系。
3. 下载网页提供的原图作为第二张参考图。不要仅凭一两句服装关键词就期待褶皱、图案和面料被精确复制。

服装库重在“穿什么”，姿势库重在“怎么站／坐／动”。场景、脸部、光线应另行指定。复杂衣服与大幅度动作可能互相冲突：宽松外套会挡住手臂，长裙会遮住腿部，这不是单靠增加提示词就能解决的。

* 第三步：给两张参考图分工

在 ChatGPT 或其他支持多图输入的图像生成工具里，上传姿势 PNG 作为图片 A，服装 PNG 作为图片 B。有固定人物需求时，再提供已获授权的人物参考图 C。

如果生成工具不支持多图参考，先用姿势图确定动作并生成基础人物，再在支持局部编辑或换装的工具中参考服装图修改服装。二阶段编辑可能改变人物面部或背景，需要单独检查；不要把“上传了两张图”当作“模型已经精确遵循两张图”。

* 想要更像真实照片，优先改什么

“超高清、8K、杰作”一类词不负责修复人体与衣服。比堆画质词更有效的是固定四件事：姿势的受力关系、衣服与身体的接触方式、现场光源方向、合理的摄影机位。

| 现象 | 先检查什么 | 怎么修改 |
|-
| 动作走样 | 选的姿势视角是否和构图冲突 | 固定全身或半身、相机高度和身体朝向；减少互相矛盾的动作描述 |
| 服装像贴图 | 衣服与手臂、肩膀和腰部是否接触合理 | 只要求衣服结构与材质，强调随动作自然产生的褶皱；必要时分阶段换装 |
| 面部像塑料 | 皮肤过度磨皮、双眼过分对称 | 加入自然皮肤纹理和不完全对称的表情；降低浓重美颜及不必要的锐化 |
| 手指、饰品错乱 | 手遮挡衣服、多个配件重叠 | 简化手部姿势或饰品，局部修复并放大检查 |
| 十张都长得相似 | 只改变衣服和背景，没有改变人物设定 | 改变年龄段（均为成年人）、五官、身形、表情、机位与光线 |

必须区分：这一轮按“姿势与服装分开设定”的思路生成，*并没有实际把两个图库的原始 PNG 上传给生图模型*。因此，这十张只能展示风格变化，不能证明两图库的组合控制精度。观察到的不足是脸型相近、皮肤偏平滑、人物个体差异较小；不应把“看起来像真人”当作“等同真实摄影”。

下一轮如果要检验图库是否真正有效，应固定同一成人角色和摄影场景，选择三张姿势 PNG 与三张服装 PNG，逐一组合，记录姿势吻合度、服装保真度、人物一致性，以及手、衣物和光影中的明显错误。

* ComfyUI 用户可以怎样接入

浏览器直接下载参考图是最简单的路径；如果经常批量试不同组合，可以再考虑第三方中文 ComfyUI 插件：

- [[https://github.com/Stone-dielianhua/ComfyUI_Pose-Gallery_ZH][ComfyUI_Pose-Gallery_ZH]]：仓库 README 记录 288 组姿势、1,439 张参考图，可在侧栏检索、切换视角、向工作流输出单图或批量图片。
- [[https://github.com/Stone-dielianhua/ComfyUI_Costume-Gallery_ZH][ComfyUI_Costume-Gallery_ZH]]：README 记录 1,407 套穿搭，可按季节、类型和颜色筛选，输出服装图及关键词。

插件负责“找到图并输出”，不是完整换装模型。两张图之后仍须接入对应模型支持的图像参考、姿势控制或图像编辑节点；不同工作流对图片参考的支持程度不同。插件包含素材，安装或分发前应分别检查插件代码与素材的许可范围，不能把代码许可证视为图片许可证。

* 参考图的使用边界

姿势库原站允许免费参考、编辑及作品创作中的商业使用，但明确禁止原图或加工图的转载、再分发、转售与自动批量下载；还禁止把人偶示意用于表现实在人物或未成年人。本篇不转载图库原始素材，只展示自行生成的示例与官方链接。服装素材的具体使用规则应以服装库页面当时的说明为准；不要未经核对就批量抓取或再发布素材。
