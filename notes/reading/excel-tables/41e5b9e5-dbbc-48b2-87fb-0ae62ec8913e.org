* 什么时候把数据区域转换为 Excel 表格
当工作表包含连续的相关数据，且需要反复筛选、引用、追加记录或维护公式时，将普通单元格区域转换为 Excel 表格（Table），通常比保留为静态数据块更方便。

表格会被 Excel 识别为一个独立对象，而不只是相邻行列中的数据。

主要收益：
- *更容易阅读*：自动应用表格格式，包括带状行。
- *筛选更方便*：列标题旁自动出现筛选按钮。
- *引用更清晰*：表格可以使用名称，公式也可以使用表格列名，减少难以理解的单元格坐标引用。
- *追加数据更省事*：紧邻表格下方或右侧新增数据时，表格通常会扩展，并延续格式；表格内公式也可能自动填充。
- *引用关系可动态更新*：依赖该表格的公式或图表可随表格新增的数据范围更新。

* 如何把普通数据区域转换为表格
1. 将光标放在数据区域任意单元格中；通常不必先选中整个区域。
2. 选择功能区的 =Insert= → =Table=。
3. 检查 Excel 自动识别的区域范围。
4. 如果范围不正确，直接修改区域引用，或使用区域选择按钮重新框选。
5. 检查 =My table has headers=（表包含标题）选项：
   - 勾选：Excel 将第一行视为列标题。
   - 不勾选：Excel 将第一行视为数据，并生成通用列名，例如 =Column1=、=Column2=。
6. 确认后创建表格。

创建成功后，标题旁会出现筛选按钮；光标位于表格内时，功能区会显示上下文选项卡 =Table Design=。当表格标题行滚出可视区域时，Excel 会在工作表列标题区域显示表格列名和筛选按钮，便于继续识别各列。

* 创建前后需要检查什么
** 检查自动识别的边界
Excel 会根据周围的空白行、空白列等信息推断数据范围。若数据区域内存在空白行或空白列，自动识别的范围可能不符合预期，创建前应手动核对。

课程示例中，原始数据位于 =B1:G11= 一带，若需要把左侧空白的 A 列也纳入表格，应将范围调整为 =A1:G11=。表格创建后，若在紧邻表格下方新增第 12 行数据，或在右侧 H 列新增数据，表格可据此扩展。

** 确认第一行是否真的是标题
只有第一行确实包含字段名称时，才应勾选 =My table has headers=。否则 Excel 会把第一行当作数据，并创建通用标题。

** 不要把表格扩展理解为自动识别任意位置的数据
动态扩展针对紧邻表格下方或右侧新增的数据。若中间隔着空白行或空白列，不能假定 Excel 会自动将远处的数据纳入表格。

* 表格名称与公式引用
Excel 表格可以使用自定义名称。公式可以通过表格名称及列名称引用数据，表达意图通常比直接引用单元格坐标更清楚，也更便于他人阅读和维护。

课程强调，表格中的列也会以名称参与公式引用。实际使用时，应给表格设置能反映内容的名称，并确保列标题清晰、唯一。

* 一个容易混淆的概念
课程所属模块名为 =Working with Pivot Tables=，但本段字幕讲的是创建普通 Excel 表格（Table），并未讲解数据透视表（PivotTable）的创建或字段配置。

两者不是同一个功能：普通表格用于组织、筛选和维护源数据；数据透视表用于汇总和分析数据。准备数据时可以先将源数据整理成表格，再根据分析目标创建数据透视表。

* 记住这几条
- 连续、结构一致的源数据，适合转换为 Excel 表格。
- 创建前核对范围和标题设置，避免遗漏列或把数据误认成标题。
- 新数据应紧邻表格边界，才能合理预期自动扩展。
- 表格名称和列名称可以让公式更易读、更易维护。

* 命名与管理 Excel 表格
** 给表格设置有意义的名称
选中表格中的任意单元格，打开 =Table Design=，在 =Properties= 区域修改 =Table Name=。Excel 创建表格时会自动分配名称，例如 =Table1=；建议改成能说明数据内容的短名称，例如 =Week1_Sales=。

表格名称规则（按本节课程说明）：
- 必须以字母、下划线（=_=）或反斜线（=\=）开头。
- 可以混合使用字母和数字。
- 不能与单元格引用冲突，例如 =WK1= 会被 Excel 识别为单元格引用；=Week1= 可用。
- 不能包含空格；需要分隔词语时可使用下划线或句点。
- 名称不区分大小写，大小写只影响可读性。
- 最长 255 个字符，但实际应优先使用简短、明确的名称。
- 同一工作簿内，表格名称必须唯一。

** 用名称管理器检查已有名称
在 =Formulas= → =Name Manager= 中，可以查看工作簿中的表格名称和其他定义名称。名称管理器会显示名称、值、引用位置、作用域和备注等信息。

图标有助于区分对象：普通命名区域的图标与表格图标不同。课程示例中的 =Team A= 是命名区域，指向 =Teams= 工作表的 =A2:A5=；新建的表格则显示表格图标。

表格会随数据变化动态调整，因此名称管理器中的表格引用范围不可像普通命名区域那样手动编辑；课程演示中该引用框为灰色。

** 在表格中插入行
1. 在需要插入位置的表格行中单击任意单元格。
2. 右键选择 =Insert= → =Table Rows Above=。
3. 在新增行中填写数据。

Excel 默认在所选位置上方插入行；插入列时则在所选列左侧插入。新增行会沿用表格的带状格式，输入新数据时也可能延续该列已有的格式，例如货币格式。

** 删除不再需要的列
1. 在待删除列中单击任意单元格。
2. 右键选择 =Delete=，再选择 =Delete Column=。

删除前确认光标位于正确的列或行中。课程示例删除了不再需要的 =ID= 列；误选位置可能导致删除错误的数据。

** 操作判断
- 需要让公式更容易理解时，给表格设置简短、能说明数据含义的名称。
- 不确定名称是否重复时，先用名称管理器检查。
- 新增记录时使用表格行插入功能，避免只在表格外添加数据。
- 删除前核对当前选中的列，避免误删。

* 格式化 Excel 表格
Excel 表格创建后，默认会套用表格样式，通常以蓝白相间的带状行区分记录。格式不只是装饰：合适的样式能帮助读者快速定位数据，但颜色过强、对比不足或设备适配差，也可能降低可读性。

** 使用 Table Design 功能区
选中表格内任意单元格，功能区会显示上下文选项卡 =Table Design=。课程将该区域分为五组：

- *Properties*：查看或修改表格名称、调整表格范围。
- *Tools*：删除重复项、连接数据透视表相关功能、插入切片器，以及将表格转换回普通数据区域。
- *External Table Data*：导出表格数据，或管理与外部资源的数据链接。
- *Table Style Options*：控制表格行列的显示方式。
- *Table Styles*：从预设样式库选择表格外观，或创建自定义样式。

** 调整行列显示
在 =Table Style Options= 中，按实际阅读需要启用或关闭以下选项：

- =Banded Rows=：隔行着色，帮助读者沿行追踪记录。
- =Banded Columns=：按列交替着色；需要强调纵向字段时使用。
- =First Column=：将第一列内容加粗。
- =Last Column=：将最后一列内容加粗。

课程示例中，启用 =Last Column= 后，F 列内容以粗体显示。行带状和列带状可以按需要选择，不必同时开启。

** 选择或自定义表格样式
=Table Styles= 提供预设样式。样式库先显示部分选项，点击展开箭头可查看完整列表。Excel 将样式分为 =Light=、=Medium= 和 =Dark= 三类，覆盖从简洁到高对比、颜色较强的设计。

选择样式前，先检查三件事：
1. 颜色是否突出关键数据，还是反而遮挡数据。
2. 在不同设备和光线环境下，文字是否仍然清晰。
3. 前景与背景的对比是否足够，能否兼顾低视力或阅读困难用户。

悬停在样式上可以预览效果；选定后，Excel 会将该样式应用到表格。课程指出，原先手动设置的格式会保留，不会因更换表格样式而被覆盖。

需要统一品牌配色时，可在样式库底部选择 =New Table Style= 创建自定义样式。自定义样式可以针对不同表格元素设置字体、边框和填充。

** 清除样式与切换主题
- 在表格样式库中选择 =Clear=，可移除当前应用的表格样式；表格本身仍然存在。
- 工作簿的 =Theme= 会影响可用的表格配色。可在 =Page Layout= → =Themes= 中切换主题，之后样式库会提供相应的配色选择。
- 若选择 =Convert to Range=，表格会变回普通数据区域，动态表格功能不再保留，但课程说明原有带状配色会留下。普通区域后续新增数据时，不应再假定带状格式会自动延续。

** 操作原则
- 先保证可读性，再考虑视觉风格；不要为了醒目而牺牲对比度。
- 大量记录优先使用清晰的行带状；字段对照需要时再考虑列带状。
- 需要突出首列或末列时，开启对应选项，不要手动逐格加粗。
- 只想改变外观时，调整样式即可；只有不再需要动态表格功能时，才使用 =Convert to Range=。

* 本节与数据透视表的区别
本节标题属于 *Working with Pivot Tables* 课程，但讲解重点是普通 Excel 表格的格式控制。功能区中的数据透视表相关入口只是其中一项工具；本节并未展开数据透视表字段布局或汇总计算的操作。
