## 7.1 按维度折叠（透视表行标签）

打开一个 DuckDB 连接即可运行。

原文 SQL

```sql
SELECT dept
FROM (
  VALUES ('Sales'),
   ('Sales'),
   ('Tech')
) t(dept)
GROUP BY dept;
```

运行结果

```text
dept
Tech
Sales
```

## 7.2 统计行数/非空计数

打开一个 DuckDB 连接即可运行。

原文 SQL

```sql
SELECT dept, COUNT(*) AS head_count
FROM (
  VALUES ('Sales', 5000),
   ('Sales', 6000),
   ('Tech', 7000)
) t(dept, salary)
GROUP BY dept;
```

运行结果

```text
dept | head_count
Tech | 1
Sales | 2
```
