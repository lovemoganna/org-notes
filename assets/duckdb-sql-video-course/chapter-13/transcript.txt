# 第 13 章｜外部文件直读

## 0:00 本章目录

这一章先解决一个问题：给 DuckDB 一个文件，能不能直接查里面的行？先看直读 CSV，再看直读 Parquet，最后动手练习。

## 0:11 01  直读 CSV

先用内嵌数据写出一个 CSV 文件，原查询再用 read CSV 直接读取它。文件是这节课的教学对象。

```sql
SELECT *
FROM read_csv('fixtures/users.csv');
```

## 0:21 02  直读 Parquet

先用内嵌数据写出一个 Parquet 文件，原查询再直接读回这张表。无需预先建表。

```sql
SELECT *
FROM read_parquet('fixtures/users.parquet');
```
