# 第 20 章｜纵向追加：按列名对齐

## 0:00 本章目录

这一章先解决一个问题：两个查询各有不同的列，怎样把它们收进一个结果？先看看两边的列名，再看核对缺失列，最后动手练习。

## 0:11 01  看两边的列名

看两个输入。左边返回列 a，值是一。右边返回列 b，值是二。

```sql
SELECT 1 AS a
UNION ALL BY NAME
SELECT 2 AS b;
```

## 0:19 02  核对缺失列

BY NAME 按列名对齐。左边那行缺 b，右边那行缺 a。结果同时有两列，两个缺口都显示 NULL。

```sql
SELECT 1 AS a
UNION ALL BY NAME
SELECT 2 AS b;
```

## 0:29 03  动手练习

暂停一下，试着做这个核对。左侧那行缺列 b，右侧那行缺列 a。

## 0:36 回顾与总结

回想刚才的例子。按列名追加可以对齐不同列，缺的值用 NULL 表示。
