# 第 19 章｜消除重复：按键保留一行

## 0:00 本章目录

这一章先解决一个问题：同一个键有两个值，该留下哪一个？先看指定去重键，再看检查留下哪一行，最后动手练习。

## 0:10 01  指定去重键

同一个键 a 有两个值。注意原例最后按 k 和 v 排序，这就让 a 的值一排在值二前面。

```sql
SELECT DISTINCT ON (k) k, v
FROM (
  VALUES ('a', 2),
   ('a', 1),
   ('b', 3)
) t(k, v)
ORDER BY k, v;
```

## 0:18 02  检查留下哪一行

DISTINCT ON 按 k 每组留一行。因为先看到值一，结果就保留 a 对应的一。b 只有一行，照常保留。

```sql
SELECT DISTINCT ON (k) k, v
FROM (
  VALUES ('a', 2),
   ('a', 1),
   ('b', 3)
) t(k, v)
ORDER BY k, v;
```

## 0:29 03  动手练习

暂停一下，试着做这个核对。a 的候选值里二先出现，因此改为保留二。

## 0:37 回顾与总结

回想刚才的例子。DISTINCT ON 决定按什么键去重，ORDER BY 决定每组先看到哪一行。
