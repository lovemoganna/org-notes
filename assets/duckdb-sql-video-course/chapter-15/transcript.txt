# 第 15 章｜横向关联与匹配：组合与存在性

## 0:00 本章目录

这一章先解决一个问题：只想确认右表有对应编号，需要把右表字段都取回来吗？先看列出所有组合，再看保留有匹配的行，再看保留无匹配的行，最后动手练习。

## 0:14 01  列出所有组合

CROSS JOIN 让左表每行和右表每行都组合一次。两行配两行，一共产生四个组合。

```sql
SELECT *
FROM (
  VALUES (1),
   (2)
) a(x)
CROSS JOIN (
  VALUES ('A'),
   ('B')
) b(y);
```

## 0:22 02  保留有匹配的行

SEMI JOIN 只问左侧有没有匹配，结果只包含左表列。这里留下二和三。

```sql
SELECT *
FROM (
  VALUES (1),
   (2),
   (3)
) a(id)
SEMI JOIN (
  VALUES (2),
   (3)
) b(id) USING (id);
```

## 0:30 03  保留无匹配的行

ANTI JOIN 留下没有任何匹配的左表行。编号一找不到对应值，所以被保留。

```sql
SELECT *
FROM (
  VALUES (1),
   (2),
   (3)
) a(id)
ANTI JOIN (
  VALUES (2),
   (3)
) b(id) USING (id);
```

## 0:47 回顾与总结

回想刚才的例子。全部组合用 CROSS，找有匹配的用 SEMI，找没有匹配的用 ANTI。
