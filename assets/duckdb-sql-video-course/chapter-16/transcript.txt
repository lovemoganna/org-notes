# 第 16 章｜模块化分步：递归

## 0:00 本章目录

这一章先解决一个问题：从一开始反复加一，查询怎样知道什么时候停？先看找起点与递推，再看核对停止条件，最后动手练习。

## 0:11 01  找起点与递推

读这段递归，先圈出起点一。递推部分每次取上一步的结果加一。

```sql
WITH RECURSIVE t(n) AS (
  VALUES (1)
  UNION ALL
  SELECT n + 1
  FROM t
  WHERE n < 3
)
SELECT *
FROM t;
```

## 0:19 02  核对停止条件

再看条件：只有当前值小于三才会继续。二满足条件，所以能生成三。三不满足，因此到这里停下。

```sql
WITH RECURSIVE t(n) AS (
  VALUES (1)
  UNION ALL
  SELECT n + 1
  FROM t
  WHERE n < 3
)
SELECT *
FROM t;
```

## 0:29 03  动手练习

暂停一下，试着做这个核对。看结果多出的一行，最后一个值应是四。

## 0:37 回顾与总结

回想刚才的例子。读递归查询，要同时找初始值、递推规则和终止条件。
