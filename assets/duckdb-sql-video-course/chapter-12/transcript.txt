# 第 12 章｜原生动态表生成

## 0:00 本章目录

这一章先解决一个问题：没有现成的表，怎么得到 0、1、2 三行？先看读取 range 的边界，再看核对生成的行，最后动手练习。

## 0:12 01  读取 range 的边界

看 range 括号里的三。只传一个数时，DuckDB 从零往上数，到三之前停下。

```sql
SELECT *
FROM range(3) t(x);
```

## 0:20 02  核对生成的行

执行查询，出来的是零、一、二。想生成零到九，就把三换成十。

```sql
SELECT *
FROM range(3) t(x);
```

## 0:27 03  动手练习

暂停一下，试着做这个核对。核对十行，第一行是零，最大值是九。

## 0:35 回顾与总结

回想刚才的例子。单参数 range 从零起步，右边界不包含在结果里。
