# 第 18 章｜排序与取前 N 行：分页

## 0:00 本章目录

这一章先解决一个问题：排好序之后，怎样跳过第一页再取下一页？先看先把结果排好，再看跳过并截取，最后动手练习。

## 0:11 01  先把结果排好

分页之前先看 ORDER BY。原始值是一、二、三，按 x 排好，位置才有意义。

```sql
SELECT x
FROM (
  VALUES (1),
   (2),
   (3)
) t(x)
ORDER BY x
LIMIT 2
OFFSET 1;
```

## 0:20 02  跳过并截取

OFFSET 一先跳过第一行，LIMIT 二再从剩下的结果取两行。因此返回二和三。

```sql
SELECT x
FROM (
  VALUES (1),
   (2),
   (3)
) t(x)
ORDER BY x
LIMIT 2
OFFSET 1;
```

## 0:28 03  动手练习

暂停一下，试着做这个核对。排序后前两行被跳过，只剩第三行，结果就只有三。

## 0:37 回顾与总结

回想刚才的例子。排序确定位置，OFFSET 跳过前面的行，LIMIT 控制页大小。
