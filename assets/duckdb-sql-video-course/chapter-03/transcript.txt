# 第 3 章｜关系命名与别名

## 0:00 本章目录

这一章先解决一个问题：看到 t.name，怎么知道它来自哪张表？先看给来源取名，再看辨认 t.name，最后动手练习。

## 0:11 01  给来源取名

给这里的两条数据起一个名字。看括号结尾，AS t 把整张小表叫作 t，后面的 name 是列名。

```sql
SELECT t.name
FROM (
  VALUES ('Alice'),
   ('Bob')
) AS t(name);
```

## 0:20 02  辨认 t.name

再回到第一行。t 点 name 的意思是，从 t 这个来源选 name 列。执行一下，两行姓名都在。

```sql
SELECT t.name
FROM (
  VALUES ('Alice'),
   ('Bob')
) AS t(name);
```

## 0:29 03  动手练习

暂停一下，试着做这个核对。把括号后的别名和点号左侧同时改成 src，姓名结果仍是 Alice 和 Bob。

## 0:41 回顾与总结

回想刚才的例子。先找 FROM 里的别名，再读点号右边的列名。
