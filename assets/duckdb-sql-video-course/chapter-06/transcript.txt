# 第 6 章｜消除重复

## 0:00 本章目录

这一章先解决一个问题：只想知道出现过哪些部门，每个部门要显示几次？先看看重复的输入，再看核对唯一部门清单，最后动手练习。

## 0:12 01  看重复的输入

原例的部门列里，Sales 出现两次，Tech 也出现两次。现在只想知道有哪些部门，把注意力放到 SELECT 后面的 DISTINCT。

```sql
SELECT DISTINCT dept
FROM (
  VALUES ('Sales'),
   ('Tech'),
   ('Sales'),
   ('Tech')
) t(dept);
```

## 0:24 02  核对唯一部门清单

执行后，每种部门只保留一次。查询没有写 ORDER BY，所以核对时看有哪些部门，不用比谁排在前面。

```sql
SELECT DISTINCT dept
FROM (
  VALUES ('Sales'),
   ('Tech'),
   ('Sales'),
   ('Tech')
) t(dept);
```

## 0:33 03  动手练习

暂停一下，试着做这个核对。唯一集合是 Sales 和 Tech，检查时允许两种行顺序。

## 0:42 回顾与总结

回想刚才的例子。DISTINCT 用输出的所有列判断两行是否重复。
