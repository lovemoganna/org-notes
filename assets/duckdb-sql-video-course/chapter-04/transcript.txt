# 第 4 章｜筛选与行过滤

## 0:00 本章目录

这一章先解决一个问题：同样叫筛选，为什么有三种写法？先看筛原始行，再看筛汇总组，再看筛窗口结果，最后动手练习。

## 0:11 01  筛原始行

WHERE 对每一行应用条件。只留下工资达到六千的记录，所以结果只有 Bob。

```sql
SELECT *
FROM (
  VALUES (1, 'Alice', 5000),
   (2, 'Bob', 7000)
) t(id, name, salary)
WHERE salary >= 6000;
```

## 0:19 02  筛汇总组

先按部门算工资总额，再用 HAVING 筛选已经算出的总额。Sales 的总额超过八千，因此保留。

```sql
SELECT dept, SUM(salary) AS total
FROM (
  VALUES ('Sales', 5000),
   ('Sales', 6000),
   ('Tech', 7000)
) t(dept, salary)
GROUP BY dept
HAVING SUM(salary) > 8000;
```

## 0:28 03  筛窗口结果

窗口先给每个部门内的记录编号，QUALIFY 再只留下编号为一的记录。这里选出 Charlie 和 Bob。

```sql
SELECT *
FROM (
  VALUES ('Alice', 'Sales', 5000),
   ('Charlie', 'Sales', 6000),
   ('Bob', 'Tech', 7000)
) t(name, dept, salary)
QUALIFY ROW_NUMBER() OVER (PARTITION BY dept
  ORDER BY salary DESC) = 1;
```

## 0:37 04  动手练习

暂停一下，试着做这个核对。仍在 WHERE 改门槛，Alice 和 Bob 都会留下。

## 0:46 回顾与总结

回想刚才的例子。先问筛选发生在哪一步：原始行用 WHERE，分组后用 HAVING，窗口计算后用 QUALIFY。
