# 第 21 章｜横向关联：时序最近值

## 0:00 本章目录

这一章先解决一个问题：时间五没有对应记录，怎样匹配它之前最近的那条？先看先确定时间方向，再看核对最近的匹配，最后动手练习。

## 0:12 01  先确定时间方向

想给时点五找一条已经发生的记录，先把方向定好。原例用大于等于，限制右侧时间不能晚于左侧。

```sql
SELECT l.t, r.v
FROM (
  VALUES (5),
   (10)
) l(t)
ASOF
LEFT JOIN (
  VALUES (3, 'a'),
   (8, 'b')
) r(t, v) ON l.t >= r.t
ORDER BY l.t;
```

## 0:22 02  核对最近的匹配

时点五之前最近的是三，所以返回 a。时点十之前最近的是八，所以返回 b。

```sql
SELECT l.t, r.v
FROM (
  VALUES (5),
   (10)
) l(t)
ASOF
LEFT JOIN (
  VALUES (3, 'a'),
   (8, 'b')
) r(t, v) ON l.t >= r.t
ORDER BY l.t;
```

## 0:30 03  动手练习

暂停一下，试着做这个核对。条件允许正好相等，因此第一条也匹配时间八，返回 b。

## 0:39 回顾与总结

回想刚才的例子。先定可匹配的时间方向，再在范围内找最近记录。
