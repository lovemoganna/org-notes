# 第 14 章｜查看与选择数据：抽样

## 0:00 本章目录

这一章先解决一个问题：一百行太多，怎样先挑五行看看？先看设置样本量，再看核对抽样结果，最后动手练习。

## 0:10 01  设置样本量

range 一百先给出零到九十九。USING SAMPLE 后面写五行，意思是从整个输入里抽五行。

```sql
SELECT *
FROM range(100) t(x) USING SAMPLE 5 ROWS;
```

## 0:19 02  核对抽样结果

如果你照着跑，具体数字可以不同。验收只检查两件事：是不是五行，数字是不是都在零到九十九之间。

```sql
SELECT *
FROM range(100) t(x) USING SAMPLE 5 ROWS;
```

## 0:29 03  动手练习

暂停一下，试着做这个核对。无论抽到哪些值，都应恰好五行，每个值都在零到九十九。

## 0:38 回顾与总结

回想刚才的例子。抽样要检查样本量与取值范围，随机抽到的具体行可以变化。
