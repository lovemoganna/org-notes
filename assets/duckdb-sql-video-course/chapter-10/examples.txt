## 10.1 多表纵向堆叠并全局去重

打开一个 DuckDB 连接即可运行。

原文 SQL

```sql
SELECT *
FROM (
  VALUES (1, 'Alice'),
   (2, 'Bob')
) t(id, name)
UNION
SELECT *
FROM (
  VALUES (1, 'Alice'),
   (3, 'Charlie')
) u(id, name);
```

运行结果

```text
id | name
2 | Bob
3 | Charlie
1 | Alice
```

## 10.2 极速无损堆叠（追加查询）

原文 SQL

```sql

FROM (
  VALUES (1, 'Alice'),

  VALUES (1, 'Alice'),
   (3, 'Charlie')
) u(id, name);
```

运行结果

```text
id | name
1 | Alice
2 | Bob
1 | Alice
3 | Charlie
```

## 10.5 提取左表独有项（核对差异丢件）

打开一个 DuckDB 连接即可运行。

原文 SQL

```sql
SELECT *
FROM (
  VALUES (1, 'Alice'),
   (2, 'Bob'),
   (3, 'Charlie')
) t(id, name)
EXCEPT
SELECT *
FROM (
  VALUES (1, 'Alice'),
   (2, 'Bob')
) u(id, name);
```

运行结果

```text
id | name
3 | Charlie
```
