# 09 · IF / AND / IFS｜把业务规则写成 IF、AND 与 IFS

## 00:00:00　先把句子拆成两个判断

这张表的复核规则有两句话。金额至少二百，状态是待处理。先看看，哪笔金额够了，却已经结案？

## 00:00:12　AND 返回真假，IF 返回标签

把两个判断装进 AND，再交给 IF。两项都成立就显示需复核，有一项不成立就显示正常。

## 00:00:22　故意测试等于门槛的一行

第六行这笔刚好二百。因为写的是大于等于，它也触发复核。等号在这里决定了边界上的订单怎么处理。

## 00:00:34　处理按顺序判断的三个档位

给成绩分档时，试着用 IFS。先看够不够九十，再看够不够六十，最后给剩下的情况一个结果。八十五分落在达标。

## 00:00:48　只改状态，检验组合逻辑

现在把第六行改成已结案。金额没变，状态这项却不再成立，结果就变成正常。这样查，知道是哪个条件导致了变化。

## 逐条拆解公式

### 00:01:01　H2　用两个同时成立的条件决定复核标签

```excel
=IF(AND(B2>=$G$2,C2="待处理"),"需复核","正常")
```

- B2>=$G$2　金额达到固定门槛。
- C2="待处理"　状态符合要求。
- AND　两项都真才进入 IF 的“需复核”分支，否则显示“正常”。

适合复核规则有多项要求，例如金额够高且尚未处理。

Excel 回读结果为 "需复核"。

### 00:01:23　H6　判断等于门槛的工单是否需复核

```excel
=IF(AND(B6>=$G$2,C6="待处理"),"需复核","正常")
```

- B6>=$G$2　包含等于 200。
- C6="待处理"　检查同一行的状态。
- AND / IF　两个判断合成真假，再选需复核或正常。

用边界记录验证规则。本行恰好 200 且为待处理，所以要复核。

Excel 回读结果为 "需复核"。

### 00:01:44　H8　按照从高到低的阈值给成绩分档

```excel
=IFS(E5>=90,"优秀",E5>=60,"达标",TRUE,"待提升")
```

- E5>=90 / "优秀"　先检查优秀档。
- E5>=60 / "达标"　再检查达标档。
- TRUE / "待提升"　前面都未命中时兜底，IFS 取第一个为真的分支。

有三个或更多互斥档位时，先列严格条件，再放通用兜底。

Excel 回读结果为 "达标"。
