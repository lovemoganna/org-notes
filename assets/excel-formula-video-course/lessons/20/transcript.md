# 20 · IF / IFNA / XLOOKUP / IFERROR｜把空键、查不到和真正计算错误分开

## 00:00:00　客服收到的是三种不同问题

查订单时，先想想三种情况。没填编号、填了但没找到，还有公式真的算不出来。用户看到的提示应该说清楚发生了什么。

## 00:00:14　先判断键是否为空

让 IF 先查看 G 二。空着就提示请输入订单号，有内容才查找。用有效编号试一下，会带回小陈。

## 00:00:26　对查找缺失使用 IFNA

如果编号有内容，但 XLOOKUP 找不到，会返回缺失错误。这时让 IFNA 接住，显示未找到。

## 00:00:37　比较两种不同的提示

先把 G 二清空，再填一个不存在的编号。留意两次提示各说了什么，你也可以在练习册里自己试一遍。

## 00:00:49　真正的除零要给不同提示

再看除法。分母是零时，IFERROR 显示检查分母。把分母改成二，六十就算出来了。

## 逐条拆解公式

### 00:01:00　H2　让空输入、查找失败和查到结果走不同路径

```excel
=IF(G2="","请输入订单号",IFNA(XLOOKUP(G2,A2:A7,B2:B7),"未找到"))
```

- G2="" / "请输入订单号"　IF 先判断输入是否空。
- XLOOKUP(G2,A2:A7,B2:B7)　有输入才按订单号精确查找并返回客户。
- IFNA(...,"未找到")　只把查无结果的错误替换成提示。

制作查询界面时，让使用者知道是该补填，还是该查订单号。

Excel 回读结果为 "小陈"。

### 00:01:23　H4　算除法并在出错时提示检查分母

```excel
=IFERROR(E2/G3,"检查分母")
```

- E2/G3　金额除以分母。
- "检查分母"　整个表达式出错时的提示。
- IFERROR　有正常结果就保留，否则用提示。它可捕获多类错误。

比率、单价或人均值的分母可能是零时，用清晰提示代替错误码。

Excel 回读结果为 "检查分母"。

## 改值复算

- 修改 G2 为 留空，H2 回读 "请输入订单号"。
- 修改 G2 为 O-999，H2 回读 "未找到"。
- 修改 G3 为 2，H4 回读 60.0。
## 独立练习

清空 G2 和填 O-999，两个提示是否相同？

### 核对

空白显示请输入订单号。O-999 显示未找到。
