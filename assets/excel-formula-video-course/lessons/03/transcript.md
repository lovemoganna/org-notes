# 03 · AVERAGE / COUNT / COUNTBLANK｜金额一样，为什么平均值变了？

## 00:00:00　先看零和空白

看金额这一列。第三行是零，第六行还没填。算平均的时候，这两个格子会一样吗？

## 00:00:10　先算一次平均值

我们先在 H 二算平均。金额加起来是四百一十，零也算一个数字。用四百一十除以五，得到八十二。

## 00:00:22　看看这一列有几个数字

换成 COUNT，确认一下分母。结果是五。要数空格，才用后面那个 COUNTBLANK。

## 00:00:31　先猜一猜，再清空零

要是把 C 三的零删掉，合计还是四百一十。先猜一下，分母会变成几？可以暂停动手算一次。

## 00:00:44　看清空后的平均值

现在只有四个数字。你会看到，平均值变成了一百零二点五。以后碰到零，先问问，它是一笔确实为零的记录，还是还没填？

## 逐条拆解公式

### 00:00:57　H2　求平均订单金额

```excel
=AVERAGE(C2:C7)
```

- C2:C7　要算均值的金额范围。
- AVERAGE　数字求和后除以数字个数，零算一个，空白跳过。

想比较典型客单价时，用它求均值，并先确认零和空白的含义。

Excel 回读结果为 82.0。

### 00:01:15　H3　数有多少个金额已录为数字

```excel
=COUNT(C2:C7)
```

- C2:C7　同一段金额列。
- COUNT　只数数值单元格，包含零，跳过空白和文字。

平均值变化时，用它检查分母，找出有多少笔真正参与计算。

Excel 回读结果为 5.0。

### 00:01:33　H4　数出金额列里有几个空白

```excel
=COUNTBLANK(C2:C7)
```

- C2:C7　要检查的金额范围。
- COUNTBLANK　数空白格，也会计入返回空文本的公式。

用来找还没登记的金额，避免把空白当成一笔零元记录。

Excel 回读结果为 1.0。

## 改值复算

- 修改 C3 为 留空，H2 回读 102.5。
- 修改 C3 为 留空，H3 回读 4.0。

清空 0 元记录 C3，均值从 82 变成多少？

### 核对

变成 102.5。总额仍为 410，进入平均的数字变成 4 个。
