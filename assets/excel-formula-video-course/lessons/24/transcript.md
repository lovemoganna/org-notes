最后试试退款。表里没有这样的记录，三项统计都应该是零。标签也要说清楚，这是无成交。你可以用同样三种情况检查自己的报表。

## 逐条拆解公式

### 00:01:07　H2　汇总指定时间和方向下的成交金额

```excel
=SUMIFS(D2:D7,B2:B7,G4,A2:A7,">="&G2,A2:A7,"<"&G3)
```

- D2:D7　成交金额列。
- B2:B7 / G4　按 G4 的方向匹配成交。
- ">="&G2 / "<"&G3　在 A 列检查含起点、不含结束时刻的时间窗。

做可切换买入、卖出等方向的报表时，改输入即可刷新金额。

Excel 回读结果为 200.0。

### 00:01:27　H3　数指定条件下的成交笔数

```excel
=COUNTIFS(B2:B7,G4,A2:A7,">="&G2,A2:A7,"<"&G3)
```

- B2:B7 / G4　匹配方向。
- A2:A7 / ">="&G2　确认在开始时刻或之后。
- A2:A7 / "<"&G3　使用不含终点的边界，COUNTIFS 数命中行。

报表要同时展示金额和笔数时，这条公式提供相同筛选口径的笔数。

Excel 回读结果为 2.0。

### 00:01:47　H4　数指定条件下的独立订单

```excel
=LET(keys,FILTER(C2:C7,(B2:B7=G4)*(A2:A7>=G2)*(A2:A7<G3)*(C2:C7<>""),""),IF(INDEX(keys,1)="",0,ROWS(UNIQUE(keys))))
```

- FILTER(...) / * / ""　按 G4 方向、G2 到 G3 时间窗筛 C 列的非空订单号，星号要求条件同真，无匹配返回空文本。
- LET(keys,...)　把筛出的订单号列表命名为 keys。
- IF / INDEX / ROWS / UNIQUE　INDEX 读首项，IF 遇空返回 0，UNIQUE 去重，ROWS 数行。

一个订单可能分成多笔成交。用它核对笔数和订单数是否相同。

Excel 回读结果为 1.0。

### 00:02:18　H5　根据成交笔数和订单数生成对账标签

```excel
=IF(H3=0,"无成交",IF(H3=H4,"逐笔对应","有拆单"))
```

- H3=0 / "无成交"　先处理零笔成交。
- H3=H4 / "逐笔对应"　有成交时比较笔数与独立订单数。
- "有拆单"　两者不相等时用这个标签。

需要让读报表的人知道窗口内是否有拆单时，用这条规则输出可读标签。

Excel 回读结果为 "有拆单"。
