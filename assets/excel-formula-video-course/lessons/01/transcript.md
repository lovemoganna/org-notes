# 01 · 加法 + / SUM｜第一条公式 · 从两格相加到整列求和

## 00:00:00　先找输入格和结果格

先看 C 列。第二行是一百二十，第四行是九十。我们找个空格，把这两个数加起来。

## 00:00:09　输入等号开始计算

在 H 二先写等号，再写 C 二加 C 四。按回车，结果是二百一十。点回这个格子，编辑栏里还看得到原公式。

## 00:00:22　用冒号表示连续范围

如果要把整列加起来，就不用一个格一个格写了。用冒号把 C 二和 C 七连起来，再交给 SUM，得到四百一十。

## 00:00:33　先猜两条公式会怎么变

试着把第一笔改成一百五十。它只多了三十，你猜两条公式的结果会各多多少？

## 00:00:44　一起核对改值后的总额

两格相加得到二百四十，整列求和是四百四十。因为两条公式都引用了 C 二。你也可以试试只改 C 五。

## 逐条拆解公式

### 00:00:57　H2　把两笔订单金额直接相加

```excel
=C2+C4
```

- C2　第一笔金额 120。
- C4　另一笔金额 90。
- +　把两格中的数相加。

常用于手头只有几笔、位置不相邻的记录。

Excel 回读结果为 210.0。

### 00:01:12　H3　把连续一列中的金额加起来

```excel
=SUM(C2:C7)
```

- C2:C7　从 C2 到 C7，首尾都算。
- SUM　将范围内的数字相加，跳过空格。

订单一多，就用范围求总额，尤其适合每天核对流水。

Excel 回读结果为 410.0。

## 改值复算

- 修改 C2 为 150，H3 回读 440.0。
## 独立练习

把第一笔金额改成 150。两格相加与总额各是多少？

### 核对

两格相加 240，总额 440。把 C2 改回 120。
