# 23 · SUMIFS / COUNTIFS / LET / FILTER / IF / INDEX / ROWS / UNIQUE｜按 15 分钟汇总：10:15 应该属于哪一窗？

## 00:00:00　先确定边界上的记录归属

这个窗口从十点整开始，十点十五截止。正好十点十五的成交放到下一窗。这样相邻的两个窗口不会都数到它。

## 00:00:12　同一行要匹配方向和两个时间条件

先算金额。SUMIFS 看买入方向和两个时间边界。两个时间判断都看 A 列，留下的一百二十和八十加起来是二百。

## 00:00:25　把金额范围去掉，就能数成交笔数

用同样的条件交给 COUNTIFS，成交是两笔。注意这两笔的订单号一样，订单数还要单独算。

## 00:00:36　先筛订单号，再数唯一值

先筛出非空的订单号，用 LET 给这个名单起个名字。名单为空就返回零。有名单时先去重，再数剩几行。

## 00:00:49　把上界延长一分钟

最后把上界推到十点十六。B 一零二也进来了。现在是四百元、三笔成交、两个订单，可以用明细逐项对一遍。

## 逐条拆解公式

### 00:01:02　H2　汇总窗口内买入成交的金额

```excel
=SUMIFS(D2:D7,B2:B7,"买入",A2:A7,">="&G2,A2:A7,"<"&G3)
```

- D2:D7　要相加的金额列。
- B2:B7 / "买入"　限定方向。
- ">="&G2 / "<"&G3　对 A 列分别检查含起点和不含结束时间。

做 15 分钟成交统计时，两个相邻窗口共享边界也只计一次。

Excel 回读结果为 200.0。

### 00:01:21　H3　数同一窗口内发生了几笔买入成交

```excel
=COUNTIFS(B2:B7,"买入",A2:A7,">="&G2,A2:A7,"<"&G3)
```

- B2:B7 / "买入"　检查成交方向。
- A2:A7 / ">="&G2　检查开始时刻及之后。
- A2:A7 / "<"&G3　截止时刻本身留给下一窗。

在金额之外加一列笔数时，沿用同样的方向和时间边界。

Excel 回读结果为 2.0。

### 00:01:39　H4　数窗口内有几张不同的买入订单

```excel
=LET(keys,FILTER(C2:C7,(B2:B7="买入")*(A2:A7>=G2)*(A2:A7<G3)*(C2:C7<>""),""),IF(INDEX(keys,1)="",0,ROWS(UNIQUE(keys))))
```

- FILTER(...) / * / ""　从 C 列筛买入且在时间窗内的非空订单号，星号要求各条件同时成立，没有匹配就返回空文本。
- LET(keys,...)　给筛出的名单起名 keys，后面重复使用。
- IF / INDEX / ROWS / UNIQUE　INDEX 读首项，IF 遇空返回 0，UNIQUE 去重，ROWS 数行。

同一订单可以分成多笔成交。计算订单数时要先按订单号去重。

Excel 回读结果为 1.0。
