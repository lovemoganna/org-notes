# 15 · IFNA / VLOOKUP / MATCH / INDEX｜读懂 VLOOKUP，再把查找拆成 MATCH 和 INDEX

## 00:00:00　旧表里，返回列号从哪里数？

VLOOKUP 从选中范围的第一列找键。A 到 E 里，订单号在第一列，金额在第五列。这个五是从范围左边开始数的。

## 00:00:12　查这一笔用精确匹配

写入订单号、范围和列号五，最后放 FALSE，表示精确匹配。找出的金额是二百二十。以后表插了列，要记得核对返回列。

## 00:00:26　把位置用一个独立公式算出来

换个思路，让 MATCH 单独告诉我们位置。范围从 A 二开始，表里的第四行就是这个范围里的第三项。

## 00:00:37　用同一位置读取另一列

把这个三交给 INDEX，在 B 列取第三项，得到小陈。查找列和返回列的起点要在同一行。

## 00:00:48　换一个订单号再查

两步对上后，再把 MATCH 套进 INDEX。改查 O 二零四，位置变成四，带回来的客户就是小郑。

## 逐条拆解公式

### 00:00:59　H2　在旧表结构里按订单号查金额

```excel
=IFNA(VLOOKUP(G2,A2:E7,5,FALSE),"未找到")
```

- G2 / A2:E7　在所选范围第一列找订单号。
- 5 / FALSE　从所选范围左侧数第 5 列，使用精确匹配。
- IFNA　查无订单时用“未找到”替换缺失错误。

维护沿用 VLOOKUP 的表时，核对查找列和返回列是否正确。

Excel 回读结果为 220.0。

### 00:01:21　H3　找到订单在查找范围里的相对位置

```excel
=MATCH(G2,A2:A7,0)
```

- G2　要找的订单号。
- A2:A7　从 A2 开始计位置。
- 0　精确匹配，返回范围内第 3 项。

想把查找拆开核对时，先确认这里返回的是第几项。

Excel 回读结果为 3.0。

### 00:01:39　H4　用查到的位置取回客户名

```excel
=INDEX(B2:B7,H3)
```

- B2:B7　要取值的客户列。
- H3　由 MATCH 算出的相对位置，第 3 项是小陈。

当位置已经由另一条公式求出时，可以据此读出其他列。

Excel 回读结果为 "小陈"。

### 00:01:56　H5　先找订单位置，再取对应客户

```excel
=IFNA(INDEX(B2:B7,MATCH(G2,A2:A7,0)),"未找到")
```

- MATCH(G2,A2:A7,0)　先精确找到相对位置。
- INDEX(B2:B7,...)　再从客户列按位置取值。
- IFNA　找不到时显示“未找到”。

想把按位置查找合成一条时使用，查找列与返回列仍要对齐。

Excel 回读结果为 "小陈"。
