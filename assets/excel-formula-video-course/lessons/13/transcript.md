# 13 · ISNUMBER / VALUE / ISBLANK / TEXT｜看起来一样的空格和数字，怎样判定类型？

## 00:00:00　先看清 Excel 读到什么类型

看起来像金额的格子，里面可能是文本。两格都看起来没写东西，也可能只有一个真的空着。我们逐个试一下。

## 00:00:11　用 ISNUMBER 告诉你是否是数值

先让 ISNUMBER 检查 D 二。虽然看见的是一百二十五点五，但底层是文字，所以返回假。

## 00:00:21　金额可以转数值，编码要保留原样

用 VALUE 把这笔文字金额转成数，再加一，得到一百二十六点五。编号开头的零有用，就把编号继续留在文本列。

## 00:00:33　对比真空格和公式空文本

再检查两个空格。F 二真空，ISBLANK 返回真。G 二有公式，只是显示为空，结果是假。

## 00:00:45　保留数值供计算，用 TEXT 做显示

如果只是做标签，TEXT 可以把数值显示成你想要的文字格式。需要汇总时，回到原来的数值列。

## 逐条拆解公式

### 00:00:56　H2　判断导入的金额底层是不是数字

```excel
=ISNUMBER(D2)
```

- D2　看起来像数字的文本金额。
- ISNUMBER　只判断是否是数值，所以本例为 FALSE。

有金额看得见却没参加计算时，先检查它是否以文本存储。

Excel 回读结果为 false。

### 00:01:13　H3　把文本金额转成数字后加一

```excel
=VALUE(D2)+1
```

- VALUE(D2)　将金额字符串解释为数字 125.5。
- +1　对实际数值执行加法，而不是把字符拼起来。

适合把导入金额恢复为可计算值。有前导零的编号可保留文本。

Excel 回读结果为 126.5。

### 00:01:34　H4　判断 F2 是真正的空单元格

```excel
=ISBLANK(F2)
```

- F2　当前未填任何内容。
- ISBLANK　真空返回 TRUE，填入 0 或公式后就会变成 FALSE。

检查输入是否填写时，可用它判断该格有没有内容。

Excel 回读结果为 true。

### 00:01:52　H5　识别看着空、实际含有公式的格子

```excel
=ISBLANK(G2)
```

- G2　放着返回空文本的公式。
- ISBLANK　有公式就返回 FALSE，显示为空也一样。

找数据缺失原因时，区分没填与公式返回空文本这两种情况。

Excel 回读结果为 false。

### 00:02:10　H6　把数值做成统一格式的展示文字

```excel
=TEXT(VALUE(D2),"#,##0.00")
```

- VALUE(D2)　先把原始文本转成数字。
- "#,##0.00"　千位分组并固定两位小数。
- TEXT　按格式输出文字。

在标签或报表摘要中固定两位小数，后续计算仍引用原数值。

Excel 回读结果为 "125.50"。

## 改值复算

- 修改 F2 为 0，H4 回读 false。
- 修改 F2 为 ""，H4 回读 false。
## 独立练习

在 F2 先填 0，再填 =""，最后清空，ISBLANK 分别返回什么？

### 核对

FALSE、FALSE、TRUE。空文本由公式产生，单元格仍有内容。
